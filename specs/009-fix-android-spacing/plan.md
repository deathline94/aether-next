# Implementation Plan: Android UI Spacing & Mobile Density Overhaul

**Branch**: `009-fix-android-spacing` | **Date**: 2026-09-18 | **Spec**: [specs/009-fix-android-spacing/spec.md](file:///C:/Users/SLiM/Desktop/Project/Aether/specs/009-fix-android-spacing/spec.md)

**Input**: Feature specification from `specs/009-fix-android-spacing/spec.md`

## Summary

Resolve massive vertical dead space (~400px per card), control dislocation, text collision, and bloated mobile layout density in the Android application's **Settings** and **Scanner** tabs. By resetting mobile flexbox properties (`flex: 0 0 auto` on title blocks, `justify-content: flex-start`, `align-items: stretch`, `gap: 10px`), neutralizing runaway vertical flex bases on multi-field port blocks (`.port-field-block`), setting an opaque solid topbar background (`#07090b`), expanding mobile controls (`.tactical-select` and `.segmented`) to full width, and removing stacked redundant margins on panel containers, this plan reduces mobile card vertical heights by over 50% and eliminates 100% of blank void spaces.
